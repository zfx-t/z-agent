# Contract deviation: ProcessLike listeners take `(...args: unknown[])` — the
# `never[]` in the contract map cannot accept a real EventEmitter/process.

# Post-review hardening (2026-09-12): the guard is now installed immediately
# after the diagnostics sink exists, before extension discovery, the trust
# prompt, session restore and tui.start(). `restoreTerminal`/`persistSession`
# bind lazily (crashTui/crashPersist), so a fault anywhere after install —
# including the previously uncovered window between tui.start() and agent
# construction — still restores the terminal, records a crash line and exits
# through the ordered shutdown. Pre-session early exits (bad flags, --help,
# list commands) still exit directly.

Verified live (2026-09-12): `timeout -s TERM --preserve-status 0.7` against
`-p --debug` — SIGTERM lands after install but while the provider fetch is in
flight → `z-agent crashed: SIGTERM (log: …)` + crash record
{terminalRestored:true, sessionPersisted:true} + EXIT=143. Signals arriving
during module load (before main() runs) still exit 143 via default
disposition — no handler can exist that early.
